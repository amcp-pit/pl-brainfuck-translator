# Транслятор Brainfuck в C

В предыдущей задачи уже познакомились с языком программирования Brainfuck и написали интерпретатор для него. 
Интерпретатор работает не быстро, но написать компилятор с нуля - не простая задача. Но для языков высокого уровня уже есть компиляторы. Почему бы тогда не попробовать написать транслятор программ на языке Brainfuck в программы на зыке C?

Нужно написать программу, которая будет:
- проверять программу на исходном языке на наличие ошибок;
- оптимизировать исходный код;
- переводить программный код Brainfuck в программный код на C.

## Проверка на наличие ошибок
Если исходный код содержит непарные фигурные скобки, то программы должна вывести в консоль `ERROR`.

## Оптимизация
Из исходного кода надо удалить все бесполезные последовательности команд, такие как: `+-`, `<>`, `[]`. 

### Примеры
- команды `++--+.` нужно превратить в `+`
- команды `[][+++]` в `[+++]`
- команды `<>><` превращаются в пустую строку ` `;

## Генерация кода на C

Последовательность N команд `+` или `-` должны быть заменены на `*p += N;\n` или `*p -= N;\n`.
### Примеры
- `++++++++++` превращается в `*p += 10;\n`
- набор команд `-----` в `*p -= 5;\n`

Последовательность N команд `>` или `<` должны быть заменены на `p += N;\n` или `p -= N;\n`.
### Примеры
- из `>>>>>>>>>>` получается `p += 10;\n`
- из `<<<<<` – `p -= 5;\n`

Команду `.` необходимо заменить на `putchar(*p);\n`.
А команду `,` необходимо заменить на `*p = getchar();\n`.

### Примеры
- `..` превращается в `putchar(*p);\nputchar(*p);\n`
- `,` в `*p = getchar();\n`

Команду `[` необходимо заменить на `if (*p) do {\n`. 
Команду `]` необходимо заменить на `} while (*p);\n`.

### Пример
Команды `[>>]` должны превратиться в 
```
if (*p) do {\n
  p += 2;\n
} while (*p);\n
```

Каждая команда в блоке кода должна быть **сдвинута на 2 пробела вправо** относительно предыдущего блока кода.
### Пример 
`[>>[<<]]` превращается в
```
if (*p) do {\n
  p += 2;\n
  if (*p) do {\n
    p -= 2;\n
  } while (*p);\n
} while (*p);\n
```

В командной строке при вызове программы указываются имена двух файлов: файла с программой на языке Brainfuck и файла, в который нужно записать код программы на языке C.

### Пример 
Командная строка: `./bf2c input.b output.c`
Файл `input.b`: `+++++[>++++.<-]`
Файл `output.c`:
```
*p += 5;
if (*p) do {
  p += 1;
  *p += 4;
  putchar(*p);
  p -= 1;
  *p -= 1;
} while (*p);
```
